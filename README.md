## 🔍 SEO & Compartilhamento

### Meta Tags Implementadas

- **Descrição e Keywords** - Para melhor indexação em buscadores
- **Open Graph Tags** - Para compartilhamento em Facebook, LinkedIn e WhatsApp
- **Twitter Card** - Otimizado para compartilhamento no Twitter/X
- **Canonical URL** - Evita conteúdo duplicado
- **Theme Color** - Cor de tema para navegadores modernos

### Dados Estruturados (Schema.org)

Implementamos Schema.org LocalBusiness para:

- Melhor indexação em Google Search
- Aparência em rich snippets
- Informações em Google Maps
- Melhor reconhecimento por assistentes de voz

### Como Compartilhar

#### WhatsApp

```
Copie a URL e compartilhe no WhatsApp. A imagem e descrição aparecerão automaticamente.
```

#### Facebook / Instagram

```
Cole a URL nos stories ou posts. O preview será gerado automaticamente com título, descrição e imagem.
```

#### Twitter/X

```
Compartilhe a URL. O card grande com imagem será exibido.
```

#### LinkedIn

```
Compartilhe a URL. Os dados estruturados serão utilizados para criar o preview.
```

## 🚀 Como Usar

### Instalação Local

1. Clone o repositório:

```bash
git clone https://github.com/mateusbhering/bseng.git
cd bseng
```

2. Abra no navegador:

```bash
# Simplesmente abra o arquivo index.html
# Ou use um servidor local (recomendado)
python -m http.server 8000
# Então acesse http://localhost:8000
```

### Editar o Projeto

- **HTML**: Modifique `index.html` para alterar conteúdo
- **CSS**: Edite `style.css` para customizar estilos
- **JavaScript**: Atualize `script.js` para adicionar funcionalidades

### Atualizar URLs do SEO

Se não estiver usando GitHub Pages, atualize as URLs no `index.html`:

```html
<meta property="og:url" content="https://www.beltraosantoseng.com.br/" />
<link rel="canonical" href="https://www.beltraosantoseng.com.br/" />
```

E também no Schema.org:

```json
"url": "https://www.beltraosantoseng.com.br/"
```

## 📊 Monitoramento

### Google Search Console

1. Acesse https://search.google.com/search-console
2. Adicione o domínio
3. Valide com um método (DNS, HTML, etc)
4. Envie o sitemap

### Google Analytics

Para adicionar tracking:

```html
<!-- Google Analytics -->
<script async src="https://www.googletagmanager.com/gtag/js?id=SEU_ID"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag() {
    dataLayer.push(arguments);
  }
  gtag("js", new Date());
  gtag("config", "SEU_ID");
</script>
```
